### Що таке Darkness Liquidation?

Darkness Liquidation — преміальний античит і плагін захисту для Minecraft-серверів. Він поєднує
предиктивну перевірку руху, аналіз пакетів, бойові перевірки, захист від експлойтів і налаштовувані
інструменти модерації, що допомагають команді сервера виявляти та припиняти нечесну гру.

Darkness Liquidation є форком [GrimAC](https://github.com/GrimAnticheat/Grim). Він використовує
предиктивну основу GrimAC та доповнює її власними перевірками, модулями захисту клієнта,
інструментами адміністрування, темами, покараннями й інтеграціями.

### Вимоги

- Java 17 або новіша для запуску плагіна.
- Сервер, сумісний із Paper. Folia підтримується.
- Чинна ліцензія Darkness — вкажіть її у `plugins/Darkness/config.yml` після першого запуску.

### Встановлення

1. Отримайте плагін Darkness Liquidation і чинну ліцензію у команди проєкту.
2. Помістіть `Darkness.jar` до папки `plugins` вашого сервера.
3. Один раз запустіть сервер, щоб створити файли конфігурації.
4. Відкрийте `plugins/Darkness/config.yml` і вкажіть ліцензію в `your_license`.
5. Перевірте налаштування перевірок, покарань, теми, логування та інтеграцій.
6. Перезапустіть сервер або виконайте `/darkness reload` після зміни конфігурації.

### Можливості

- Предиктивні перевірки руху, aim, reach, velocity, inventory, scaffold, timer, elytra, транспорту,
  пакетів та інших механік.
- Система репутації TrustFactor з динамічним масштабуванням сетбеків і збереженням у БД.
- Автоматичне оновлення конфігурацій зі збереженням користувацьких значень і коментарів.
- Захист від некоректних пакетів, спроб крашу, підозрілих даних клієнта, blink-подібної поведінки та
  інших зловживань протоколом.
- Модулі приховування інформації, що зменшують переваги чит-клієнтів через підміну окремих даних,
  видимих клієнту.
- Моніторинг брендів клієнтів і правила для підозрілих або заблокованих клієнтів.
- Алерти, verbose-вивід, профілі гравців, метрики продуктивності, логи, Discord-вебхуки та передавання
  алертів через проксі.
- Гнучкі покарання, punishment wave, інструменти модерації, теми й конфігурації англійською,
  російською та українською мовами.
- Необов'язкові інтеграції з ViaVersion, ViaBackwards, Geyser, Floodgate, LuckPerms і PlaceholderAPI.
- Підтримка Paper і Folia.

### Предиктивний рушій

Darkness Liquidation побудований на предиктивній основі GrimAC. Замість перевірки лише простих
лімітів пакетів рушій відтворює набір рухів, які ванільний клієнт міг виконати легітимно, і
зіставляє вхідні дії з цією моделлю.

- **Симуляція ванільного руху.** Враховуються ходьба, плавання, відкидання, павутина, бульбашкові
  колони, транспорт, елітри та інші механіки ванільного Minecraft.
- **Фізика й колізії з урахуванням версій.** Обробляються відмінності версій клієнта і сервера,
  порядок колізій, зміни хітбоксів, блоки-замінники ViaVersion і дані блоків, що залежать від версії.
- **Реплікація світу для кожного гравця.** Античит створює кеш клієнтського представлення світу з
  пакетів чанків, встановлення та зміни блоків. Це дає змогу безпечно враховувати пакетні й
  підроблені блоки без автоматичних хибних спрацьовувань.
- **Компенсація затримки й інвентарю.** Зміни світу, станів гравця та дані інвентарю враховуються
  в порядку їх отримання клієнтом, що зменшує хибні спрацьовування через пінг, ghost blocks і
  десинхронізацію.
- **Асинхронна архітектура.** Більшість обробки руху та слухачів працює поруч із мережевим
  конвеєром; дані гравців розраховані на безпечний паралельний доступ і масштабування.
- **Безпека завдяки точній симуляції.** Перевірки зіставляють дії з можливою ванільною поведінкою,
  щоб відрізняти недопустимий рух без опори лише на приховування логіки.

### Система TrustFactor

Darkness відстежує репутацію гравців між сесіями для динамічного масштабування покарань:

- **Оцінка довіри.** Гравці мають рейтинг довіри (від 0 до 100), обернено пропорційний накопиченим
  очкам порушень. Менше очок означає вищий рівень довіри.
- **Рівні довіри:**
  - `GREEN` (0–100 очок): Перевірений гравець. М'які сетбеки (`GRIM`) без дискомфорту для гри.
  - `ORANGE` (101–350 очок): Підозра. Проміжний сетбек (`GRIM_AIR`) з обмеженням руху в повітрі.
  - `RED` (> 350 очок): Чітер. Жорсткий миттєвий відкат (`DARKNESS`) з фіксацією координат.
- **Динамічні сетбеки.** Перевірки з `setback_type: TRUST` автоматично підлаштовують суворість
  відкату під поточний рівень довіри гравця.
- **Збереження в базі даних.** Рівні довіри зберігаються між перезапусками через асинхронний запис
  пакетами в SQLite, MySQL або PostgreSQL.
- **Плейсхолдери.** Підтримуються плейсхолдери `%trust_score%`, `%trust_points%`, `%trust_level%`,
  `%trust_color%`, `%trust_type%` та `%trust_banned%`.

### API для розробників

Darkness надає API для інтеграції з користувацькими плагінами та серверними системами. Воно дозволяє
створювати розширення навколо подій і можливостей Darkness без залежності від внутрішніх деталей
реалізації.

- Репозиторій API та документація: [1hendex/DarknessAPI](https://github.com/1hendex/DarknessAPI)

### Конфігурація

Основні файли створюються у `plugins/Darkness/`. Початкові конфігурації у репозиторії:

- [`config/uk.yml`](src/main/resources/config/uk.yml) — загальні налаштування, алерти, захист клієнта,
  Discord, логи, покарання та інтеграції.
- [`checks/uk.yml`](src/main/resources/checks/uk.yml) — перевірки античита та їхні параметри.
- [`hider/uk.yml`](src/main/resources/hider/uk.yml) — модуль Information Hider, пакетний анти-ESP
  та маскування даних клієнта.
- [`punishments/uk.yml`](src/main/resources/punishments/uk.yml) — правила покарань за порушення.
- [`themes/`](src/main/resources/themes) — теми алертів і повідомлень.

Змінюйте параметри поступово та перевіряйте їх на своєму сервері, перш ніж вмикати суворі покарання
на продакшені.

### Повний список команд

Основна команда за замовчуванням — `/darkness`. Назву команди та аліаси можна змінити у `config.yml`
через `command_name`, наприклад `command_name: darkness,dl`; перше ім'я стане основною командою, а
решта — аліасами. Після зміни налаштування перезапустіть сервер. Аргументи у `<кутових дужках>`
обов'язкові, у `[квадратних дужках]` — необов'язкові.

| Command | Призначення |
| --- | --- |
| `/darkness` | Показати інформацію про плагін і версію. |
| `/darkness help` | Показати внутрішньоігрову довідку. |
| `/darkness alerts` | Увімкнути або вимкнути алерти про порушення. |
| `/darkness verbose` | Увімкнути або вимкнути докладний вивід порушень. |
| `/darkness brands` | Увімкнути або вимкнути сповіщення про бренди клієнтів. |
| `/darkness profile <гравець>` | Відкрити античит-профіль гравця. |
| `/darkness topvl` | Показати гравців із найвищим рівнем порушень. |
| `/darkness cps <гравець>` | Показати CPS гравця. |
| `/darkness checks` | Показати доступні перевірки. |
| `/darkness checks enable <перевірка>` | Увімкнути перевірку. |
| `/darkness checks disable <перевірка>` | Вимкнути перевірку. |
| `/darkness debug [гравець]` | Перемкнути відлагоджувальний вивід гравця. |
| `/darkness consoledebug <гравець>` | Перемкнути відлагоджувальний вивід у консолі для гравця. |
| `/darkness perf` або `/darkness performance` | Перемкнути метрики продуктивності. |
| `/darkness lag` | Показати дані про ресурси та затримки сервера. |
| `/darkness menu` | Відкрити головне меню Darkness. |
| `/darkness themes` | Відкрити меню вибору тем. |
| `/darkness logs [гравець] [сторінка]` | Відкрити GUI логів порушень або переглянути логи гравця. |
| `/darkness reload` | Перезавантажити конфігурацію Darkness. |
| `/darkness sendalert <повідомлення>` | Надіслати власний алерт для персоналу. |
| `/darkness bot [гравець]` | Створити тестового бота біля себе або вибраного гравця. |
| `/darkness spectate <гравець>` | Почати спостереження за гравцем. |
| `/darkness stopspectating [here]` | Завершити спостереження; `here` залишає вас у поточній точці за наявності права. |
| `/darkness knockback <гравець> [back]` або `/darkness kb <гравець> [back]` | Запустити перевірку відкидання. |
| `/darkness totem <гравець>` | Запустити перевірку AutoTotem. |
| `/darkness rotate <гравець>` | Повернути гравця як дію модератора. |
| `/darkness shuffle <гравець> <one/many>` | Перемішати слоти інвентарю гравця. |
| `/darkness punish <гравець> [причина]` | Застосувати налаштоване покарання. |
| `/darkness kick <гравець> [причина]` | Кікнути гравця. |
| `/darkness crash <гравець> <метод>` | Запустити налаштований метод стрес-тесту клієнта. Варианти: `entity`, `explosion`, `position`, `particle`, `sound`, `loadworld`, `demo`, `fakelag`, `black`, `multi`, `inverse`, `chunk`. |
| `/darkness trust <add/remove/set/clear/info> <гравець> [бали]` | Керування або перегляд балів і рівня TrustFactor гравця. |

### Information Hider

Information Hider налаштовується в окремому файлі конфігурації `hider.yml` (у репозиторії:
`hider/uk.yml`). Модуль підміняє пакетні дані, блокуючи збір інформації читами та приховуючи
гравців за перешкодами на мережевому рівні.

| Налаштування | Що вони роблять |
| --- | --- |
| enabled; onlyForPlayers | Вмикають модуль і обмежують його обробку лише гравцями. |
| parts.health.value; random | Відправляють фіксоване здоров'я від 0 до 20, за потреби випадкове. Значення 0 порушує анімацію ходьби. Значення -1 вимикає підміну. |
| parts.xp; air; saturation; absorption | Приховують досвід, повітря, насичення та золоті серця поглинання. |
| parts.ping; gamemode; seed | Маскують пінг у табі, режим гри та сід світу. |
| parts.scoreboard.enabled; patterns | Маскують здоров'я у відповідних скорбордах і таб-листі за ключовими патернами назв цілей. |
| parts.enchant; item_count; item_name; item_drop; durability | Маскують зачарування, кількість, назви предметів, дані викинутого луту та міцність. |
| parts.potion; potion_items; end_effect | Приховують ефекти зілля та тип зілля в руках/стрілах, заспамлюючи список ефектів чита фейковими пакетами. |
| parts.server_brand.enabled; brand | Підміняють назву бренду сервера на екрані налагодження F3. |
| parts.esp.enabled; max_distance; max_fov; proximity_distance | Пакетний анти-ESP: приховує гравців за стінами та блоками через трасування променів. Підтримує фільтрацію за дистанцією та кутом огляду (FOV). |
| parts.esp.hide_delay_ticks; interval_ticks; only_sneaking | Налаштування тіків затримки під час виходу з-за рогу, інтервалу перерахунку та приховування лише крадькома для оптимізації CPU. |
| parts.esp.effects; ignored_blocks; disabled_worlds | Налаштування приховування при сліпоті/темряві/невидимості, перелік прозорих блоків-винятків та вимкнених світів. |
| parts.inventory | Перемішує предмети під час руху, ламаючи AutoTotem та InvWalk. |
| parts.chest_loot | Приховує вміст скрині в момент відкриття, ламаючи роботу ChestStealer. |
| parts.totem.enabled; mode; amount; spawn_tab; height | Ламає TotemPopCounter через дублікати пакетів (duplicate) або фейкових ботів під землею (bot). |
| parts.fake_staff.enabled; only_random_name; roles; bots | Створює клієнтських фейкових працівників персоналу в табі для маскування справжніх модераторів. |
| parts.spectators.allowed_worlds; hide_spectators | Обмежує приховування спостерігачів указаними світами та приховує гравців із правом darkness.spectator. |
