### Что такое Darkness Liquidation?

Darkness Liquidation — премиальный античит и плагин защиты для Minecraft-серверов. Он сочетает
предиктивную проверку движений, анализ пакетов, aim-проверки, защиту от эксплойтов и настраиваемые
инструменты модерации, помогая команде сервера выявлять и пресекать нечестную игру.

Darkness Liquidation является форком [GrimAC](https://github.com/GrimAnticheat/Grim). В его основе
лежит предиктивный движок GrimAC, расширенный собственными проверками, модулями защиты клиента,
административными инструментами, темами, наказаниями и интеграциями.

### Требования

- Java 17 или новее для запуска плагина.
- Сервер, совместимый с Paper. Folia поддерживается.
- Действующая лицензия Darkness — укажите её в `plugins/Darkness/config.yml` после первого запуска.

### Установка

1. Получите плагин Darkness Liquidation и действующую лицензию у команды проекта.
2. Поместите `Darkness.jar` в папку `plugins` вашего сервера.
3. Один раз запустите сервер, чтобы создать файлы конфигурации.
4. Откройте `plugins/Darkness/config.yml` и укажите лицензию в `your_license`.
5. Проверьте настройки проверок, наказаний, темы, логирования и интеграций.
6. Перезапустите сервер или выполните `/darkness reload` после изменения конфигурации.

### Возможности

- Предиктивные проверки движения, aim, reach, velocity, inventory, scaffold, timer, elytra,
  транспорта, пакетов и других механик.
- Система репутации TrustFactor с динамическим масштабированием сетбеков и сохранением в БД.
- Автоматический апдейтер конфигураций с сохранением пользовательских порогов и комментариев.
- Защита от некорректных пакетов, краш-попыток, подозрительных данных клиента, blink-подобного
  поведения и других злоупотреблений протоколом.
- Модули скрытия информации, уменьшающие преимущества чит-клиентов через подмену выбранных данных,
  видимых клиенту.
- Мониторинг брендов клиентов и правила для подозрительных или запрещённых клиентов.
- Алерты, verbose-вывод, профили игроков, метрики производительности, логи, Discord-вебхуки и
  пересылка алертов через прокси.
- Гибкие наказания, punishment wave, инструменты для модерации, темы и конфигурации на английском,
  русском и украинском языках.
- Необязательные интеграции с ViaVersion, ViaBackwards, Geyser, Floodgate, LuckPerms и
  PlaceholderAPI.
- Поддержка Paper и Folia.

### Предиктивный движок

Darkness Liquidation построен на предиктивной основе GrimAC. Вместо проверки только простых лимитов
пакетов движок воссоздаёт набор движений, которые ванильный клиент мог выполнить легитимно, и
сравнивает входящие действия с этой моделью.

- **Симуляция ванильного движения.** Учитываются ходьба, плавание, отбрасывание, паутина,
  пузырьковые колонны, транспорт, элитры и другие механики ванильного Minecraft.
- **Физика и коллизии с учётом версий.** Обрабатываются различия версий клиента и сервера, порядок
  коллизий, изменения хитбоксов, блоки-замены ViaVersion и данные блоков, зависящие от версии.
- **Репликация мира для каждого игрока.** Античит создаёт кэш клиентского представления мира из
  пакетов чанков, установки и изменения блоков. Это позволяет безопасно учитывать пакетные и
  поддельные блоки без автоматических ложных срабатываний.
- **Компенсация задержки и inventory.** Изменения мира, состояния игрока и данные inventory
  учитываются в порядке их получения клиентом, что снижает ложные срабатывания из-за пинга,
  ghost blocks и рассинхронизации.
- **Асинхронная архитектура.** Большая часть обработки движения и слушателей работает рядом с
  сетевым конвейером; данные игроков рассчитаны на безопасный параллельный доступ и масштабирование.
- **Безопасность за счёт точной симуляции.** Проверки сопоставляют действия с возможным ванильным
  поведением, чтобы отличать недопустимое движение без опоры только на скрытность логики.

### Система TrustFactor

Darkness отслеживает репутацию игроков между сессиями для адаптивного применения ограничений:

- **Оценка доверия.** Игроки имеют показатель доверия (от 0 до 100), обратно пропорциональный
  накопленным очкам нарушений. Чем меньше очков, тем выше доверие.
- **Уровни доверия:**
  - `GREEN` (0–100 очков): Доверенный. Мягкие сетбеки (`GRIM`) не мешают честной игре.
  - `ORANGE` (101–350 очков): Подозрение. Сетбек (`GRIM_AIR`) с ограничением движений
    в воздухе.
  - `RED` (> 350 очков): Читер. Жёсткий моментальный откат (`DARKNESS`) с фиксацией позиции.
- **Динамические сетбеки.** Проверки с `setback_type: TRUST` автоматически масштабируют строгость
  наказания в зависимости от текущего уровня доверия игрока.
- **Хранение в базе данных.** Данные сохраняются между перезапусками сервера через асинхронный сброс
  батчей в SQLite, MySQL или PostgreSQL.
- **Плейсхолдеры.** В сообщениях и PlaceholderAPI доступны `%trust_score%`, `%trust_points%`,
  `%trust_level%`, `%trust_color%`, `%trust_type%` и `%trust_banned%`.

### API для разработчиков

Darkness предоставляет API для интеграции с пользовательскими плагинами и серверными системами.
Оно позволяет создавать расширения вокруг событий и возможностей Darkness, не завися от внутренних
деталей реализации.

- Репозиторий API и документация: [1hendex/DarknessAPI](https://github.com/1hendex/DarknessAPI)

### Конфигурация

Основные файлы создаются в `plugins/Darkness/`. Исходные конфигурации в репозитории:

- [`config/ru.yml`](src/main/resources/config/ru.yml) — общие настройки, алерты, защита клиента,
  Discord, логи, наказания и интеграции.
- [`checks/ru.yml`](src/main/resources/checks/ru.yml) — проверки античита и их параметры.
- [`hider/ru.yml`](src/main/resources/hider/ru.yml) — модуль Information Hider, пакетный анти-ESP
  и маскировка данных клиента.
- [`punishments/ru.yml`](src/main/resources/punishments/ru.yml) — правила наказаний за нарушения.
- [`themes/`](src/main/resources/themes) — темы алертов и сообщений.

Меняйте параметры постепенно и проверяйте их на своём сервере, прежде чем включать строгие наказания
на продакшене.

### Полный список команд

Основная команда по умолчанию — `/darkness`. Название команды и алиасы можно изменить в `config.yml`
через `command_name`, например `command_name: darkness,dl`; первое имя станет основной командой, а
остальные — алиасами. После изменения настройки перезагрузите сервер. Аргументы в `<угловых
скобках>` обязательны, в `[квадратных скобках]` — необязательны.

| Command | Назначение |
| --- | --- |
| `/darkness` | Показать информацию о плагине и версии. |
| `/darkness help` | Показать внутриигровую справку. |
| `/darkness alerts` | Включить или выключить алерты о нарушениях. |
| `/darkness verbose` | Включить или выключить подробный вывод нарушений. |
| `/darkness brands` | Включить или выключить уведомления о брендах клиентов. |
| `/darkness profile <игрок>` | Открыть античит-профиль игрока. |
| `/darkness topvl` | Показать игроков с наибольшим уровнем нарушений. |
| `/darkness cps <игрок>` | Показать CPS игрока. |
| `/darkness checks` | Показать доступные проверки. |
| `/darkness checks enable <проверка>` | Включить проверку. |
| `/darkness checks disable <проверка>` | Выключить проверку. |
| `/darkness debug [игрок]` | Переключить отладочный вывод игрока. |
| `/darkness consoledebug <игрок>` | Переключить отладочный вывод в консоли для игрока. |
| `/darkness perf` или `/darkness performance` | Переключить метрики производительности. |
| `/darkness lag` | Показать данные о ресурсах и задержках сервера. |
| `/darkness menu` | Открыть главное меню Darkness. |
| `/darkness themes` | Открыть меню выбора тем. |
| `/darkness logs [игрок] [страница]` | Открыть GUI логов нарушений или просмотреть логи игрока. |
| `/darkness reload` | Перезагрузить конфигурацию Darkness. |
| `/darkness sendalert <сообщение>` | Отправить пользовательский алерт для персонала. |
| `/darkness bot [игрок]` | Создать тестового бота возле себя или выбранного игрока. |
| `/darkness spectate <игрок>` | Начать наблюдение за игроком. |
| `/darkness stopspectating [here]` | Закончить наблюдение; `here` оставляет вас на текущем месте при наличии права. |
| `/darkness knockback <игрок> [back]` или `/darkness kb <игрок> [back]` | Запустить проверку отбрасывания. |
| `/darkness totem <игрок>` | Запустить проверку AutoTotem. |
| `/darkness rotate <игрок>` | Повернуть игрока как действие модератора. |
| `/darkness shuffle <игрок> <one/many>` | Перемешать слоты inventory игрока. |
| `/darkness punish <игрок> [причина]` | Применить настроенное наказание. |
| `/darkness kick <игрок> [причина]` | Кикнуть игрока. |
| `/darkness crash <игрок> <метод>` | Запустить настроенный метод стресс-теста клиента. Варианты: `entity`, `explosion`, `position`, `particle`, `sound`, `loadworld`, `demo`, `fakelag`, `black`, `multi`, `inverse`, `chunk`. |
| `/darkness trust <add/remove/set/clear/info> <игрок> [очки]` | Управление или просмотр очков и уровня TrustFactor игрока. |

### Information Hider

Information Hider настраивается в отдельном файле конфигурации `hider.yml` (в репозитории:
`hider/ru.yml`). Модуль подменяет пакетные данные, блокируя сбор информации читами и скрывая
игроков за препятствиями на сетевом уровне.

| Настройки | Что они делают |
| --- | --- |
| enabled; onlyForPlayers | Включают модуль и ограничивают его обработку только игроками. |
| parts.health.value; random | Отправляют фиксированное здоровье от 0 до 20, при необходимости случайное. Значение 0 сбивает анимацию ходьбы. Значение -1 отключает подмену. |
| parts.xp; air; saturation; absorption | Скрывают опыт, воздух, насыщение и золотые сердца поглощения. |
| parts.ping; gamemode; seed | Маскируют пинг в табе, режим игры и сид мира. |
| parts.scoreboard.enabled; patterns | Маскируют здоровье в подходящих скорбордах и таб-листе по ключевым паттернам названий целей. |
| parts.enchant; item_count; item_name; item_drop; durability | Маскируют зачарования, количество, названия предметов, данные выброшенного лута и прочность. |
| parts.potion; potion_items; end_effect | Скрывают эффекты зелий и тип зелья в руках/стрелах, заспамливая список эффектов чита поддельными пакетами. |
| parts.server_brand.enabled; brand | Подменяют имя бренда сервера на экране отладки F3. |
| parts.esp.enabled; max_distance; max_fov; proximity_distance | Пакетный анти-ESP: скрывает игроков за стенами и блоками на уровне трассировки лучей. Поддерживает фильтрацию по дистанции и углу обзора (FOV). |
| parts.esp.hide_delay_ticks; interval_ticks; only_sneaking | Настройка тиков задержки при выходе из-за угла, интервала перерасчёта и режима скрытия только крадущихся игроков для оптимизации CPU. |
| parts.esp.effects; ignored_blocks; disabled_worlds | Настройка скрытия при слепоте/тьме/невидимости, список исключаемых прозрачных блоков и отключённых миров. |
| parts.inventory | Перемешивает предметы при перемещении, ломая AutoTotem и InvWalk. |
| parts.chest_loot | Скрывает содержимое сундука на момент открытия, ломая логику ChestStealer. |
| parts.totem.enabled; mode; amount; spawn_tab; height | Ломает TotemPopCounter через дублирующие пакеты (duplicate) или фейковых ботов под землей (bot). |
| parts.fake_staff.enabled; only_random_name; roles; bots | Создаёт клиентских фейковых сотрудников персонала в табе для маскировки настоящих модераторов. |
| parts.spectators.allowed_worlds; hide_spectators | Ограничивает скрытие наблюдателей указанными мирами и скрывает игроков с правом darkness.spectator. |
